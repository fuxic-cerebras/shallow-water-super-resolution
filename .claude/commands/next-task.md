# Choose and plan the next task

Read `CLAUDE.md`, the linked design documents, and `TASKS.md`. Select the first
unchecked task whose prerequisites are complete.

Before coding:

1. Restate the task and its acceptance criterion.
2. Identify the smallest set of files that should change.
3. Identify tests that must be added or updated.
4. Call out any conflict with `docs/DECISIONS.md`.

Implement only that task. Run focused tests and then the fast full suite. Summarize
measured results, remaining risks, and the next blocked or ready task. Do not fabricate
missing experiment results and do not check off work whose acceptance criterion failed.
